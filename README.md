# Front Path

Arrow-slide path puzzle — **WeChat mini-game** + browser.

**Play:** https://ningyixi.github.io/front-path/?v=7

## Features

- **Difficulty** — Easy / Medium / Hard (board fill ~25% / ~55% / ~85%)
- **Normal Mode** — stopwatch, chase best clear times
- **Timed Mode** — per-level countdown; fail & retry if time hits 0
- 50 DFS-solvable levels per difficulty on **tall portrait boards**
- Concurrent slides — tap the next arrow while others move
- One-tap **Menu** back to the start screen while playing
- Best times saved locally (per mode + difficulty)
- English UI, soft sound toggle

## Controls

Tap an arrow to slide it off the board in its facing direction. Clear the board to win.

## WeChat

Open this folder in WeChat DevTools as a **游戏** project (`touristappid`).
